# singular-lms-home

The one-page business site at `https://singular-lms.com`, served by GitHub Pages. The product itself is a separate (private) repository and runs at `https://app.singular-lms.com`.

- Plain HTML and CSS. No JavaScript, no tracking, no forms, no build step.
- Colors in `style.css` are copied from the app's design tokens. Update them by hand if the brand changes.
- Contact is a `mailto:` link only.
- `CNAME` holds the custom domain. Do not delete it.
- Do not put secrets, household data or anything private in this repository: it is public.

Why this hosting: see ADR-0023 in the main repository.
